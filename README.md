# 🐍 Python Practice & Problem Solving

This repository contains the Python practice exercises I worked on while learning and strengthening my programming fundamentals.

Instead of only learning concepts from theory, I practiced by solving different problems and writing Python programs for them.

## 📚 What I Practiced

- Functions
- Conditional statements
- Loops
- Strings
- Input and output
- Basic problem solving
- Logical thinking

## 📂 Practice Sets

### Practice Set 1
Basic Python exercises covering functions, input/output, calculations, conditions and other programming fundamentals.

### Practice Set 2
Exercises based on conditional logic, including BMI calculation, age classification, discounts, leap years and number comparisons.

### Practice Set 3
Exercises focused on loops and functions, including string reversal, multiplication tables, character counting, squares and cubes, and FizzBuzz.

## 🎯 What I Learned

These exercises helped me become more comfortable with Python syntax and, more importantly, with approaching a problem and thinking about how to solve it step by step.

Some problems were simple, while others required more thinking and debugging. Each exercise gave me an opportunity to practice and improve.
